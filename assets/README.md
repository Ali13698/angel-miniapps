# پوشه Assets

این پوشه شامل کتابخانه‌های شخص ثالث (Third-party) است که به صورت لوکال ذخیره شده‌اند تا از فیلترشکن و CDNهای خارجی بی‌نیاز باشیم.

## فایل‌های مورد نیاز:
1. `telegram-web-app.js` (از مخزن قدیمی کپی شود)
2. `protobuf.min.js` (از مخزن قدیمی کپی شود)
3. `cropper.min.js` (از مخزن قدیمی کپی شود)
4. `cropper.min.css` (از مخزن قدیمی کپی شود)
5. `angel.proto` (فایل پروتکل بازی)

**توجه به AL بعدی:** این فایل‌ها نباید تغییر کنند یا از نو نوشته شوند. آن‌ها را دقیقاً از مخزن `angel-game-api` (مسیر `internal/web/static/js/`) به اینجا کپی کنید.
